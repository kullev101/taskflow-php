
# TaskFlow

A simple task management application built with PHP, MySQL, HTML, CSS and JavaScript.

## Project Overview

TaskFlow is a personal task management application that allows users to create, manage and track their tasks.

The project is being developed step by step as a learning project.

## Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git
