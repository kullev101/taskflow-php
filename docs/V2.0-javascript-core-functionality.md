# V2.0 — JavaScript Core Functionality

## Implemented Features
- Add tasks using the form button.
- Add tasks by pressing Enter.
- Prevent adding empty or whitespace-only tasks.
- Toggle task completion using checkboxes.
- Delete tasks.
- Use event delegation for handling task deletion.

## Notes
Task completion styling is handled by CSS using the `:has()` selector and the native checkbox state.
