# V1.0 — Static Layout

## Implemented Features

- Created the main application layout.
- Added a sidebar with task statistics.
- Added the main workspace.
- Created a task input form.
- Added a static list of sample tasks.
- Implemented responsive layout for different screen sizes.

## Limitations

- Tasks are currently static.
- Adding tasks is not functional.
- Deleting tasks is not functional.
- Task completion is not connected to application logic.
- No database or backend integration yet.

## Next Version

V2.0 — JavaScript Core Functionality.

The next version will introduce task creation, deletion, completion and basic input validation.
